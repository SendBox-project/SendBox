## 배운 점 & 아쉬운 점

<p align="justify">
<span> A - DB 설계의 중요성을 느꼈습니다.  개발을 하면서 단순히 기능 구현에만 신경을 쓰고 ‘ DB는 이렇게 하면 되겠지 ? ‘ 정도만 생각하고 개발을 시작했는데 이런 어리석은 생각으로 인해 DB를 여러 번 수정하는 고생을 겪었습니다. 다음 프로젝트에서는 DB를 효율적으로 설계하기 위해 노력하고자 합니다.
</span><br>
  <span>B - 처음에 프로젝트를 시작하게 됐을때는 의욕이 넘쳐서 최대한 많은 기능을 구현해 보고 싶었으나 프로젝트를 실제로 하는 중에서 생각과 달리 많은 오류들이 생겨서 계획보다는 적게 기능을 구현하게 됐지만 실력적으로 많이 성장하게된 프로젝트인거 같습니다
</span><br>
  <span>C - 처음 프로젝트를 진행하면서 처음 기획을 하게 되었는데 그 첫 기획이 실제로 구현이 되는 걸 보면서 뿌듯함을 느꼈습니다. 백엔드와 프론트엔드를 다 진행하면서 제가 어떤 부분에 어려움을 겪고 어떤 부분에 흥미를 느끼는지 알게 된 시간이었던 거 같습니다. 다음 프로젝트에서는 부족한 부분을 더 보완해서 효율적으로 작업을 하고싶습니다.
</span><br>
</p>
